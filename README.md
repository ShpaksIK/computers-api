# Система для магазина компьютерной техники 

Серверное приложение на Express для магазина компьютерной техники.

## Инструкция по установке и запуску
### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd <название-папки>
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
Создайте файл `.env` в корне проекта и подставьте свои значения в переменные:
```env
DB_USER=имяПользователя
DB_PASSWORD=парольПользователя
DB_SERVER=адресСервера
DB_PORT=порт
DB_DATABASE=названиеБД
```

### 4. Запуск сервера
```bash
npm run start
```
Сервер будет доступен по адресу: `http://localhost:5000`

## Функционал по ролям
### Администратор
- Регистрация и авторизация
- Управление профилем
- Управление пользователями (просмотр, изменение, удаление)

### Менеджер
- Регистрация и авторизация
- Управление профилем
- Управление товарами (просмотр, изменение, удаление)

### Пользователь
- Регистрация и авторизация
- Управление профилем
- Просмотр каталога товаров
- Управление корзиной (добавление/удаление товаров)
- Оформление покупок
- Просмотр истории покупок
